# OSCALY Academic Bash Course

This repository collects practice material from a Bash scripting course focused on Linux shell fundamentals, control flow, and network-oriented automation. The project is organized into four sections that move from basic scripting syntax to practical scanning utilities.

## Course Goals

- Understand how Bash works as a shell and script interpreter.
- Practice variables, arrays, arithmetic, streams, and redirection.
- Learn conditional logic, functions, and looping constructs.
- Apply Bash to simple network automation tasks such as host generation, subdomain generation, port monitoring, and subnet scanning.

## Repository Structure

### Section1: Bash Fundamentals

This section introduces the basics of writing and running shell scripts.

- `hello.sh`: first executable Bash script, uses `set -x`, `sleep`, and simple command chaining.
- `create.sh`: creates a directory and file, then lists content.
- `variable.sh`: demonstrates variables, command substitution, and `unset`.
- `arithmetic.sh`: basic arithmetic with Bash arithmetic expansion.
- `arrays.sh`: indexed arrays, element access, printing, and removing items.
- `streams.sh`: explains `STDIN`, `STDOUT`, and `STDERR` with a simple error-producing example.
- `redirection.sh`: covers output redirection, append operators, heredocs, and pipes.
- `positional_arguements.sh`: uses `$0`, `$1`, `$@`, and `$#` with a `ping` example.
- `interactive_scripts.sh`: reads user input with `read -r`.
- `exit_codes.sh`: shows command exit codes and manual script exit status.
- `jobs.sh`: simulates a long-running background-style task and logs progress.
- `Cat.txt`, `Untitle.txt`, `long_task.log`, `long_task.long`: output files generated by practice scripts.

Main topics in this section:

- Shebangs and script execution
- Debug mode with `set -x`
- Variables and command substitution
- Arithmetic and arrays
- Standard streams and redirection
- Positional parameters and interactive input
- Exit codes and logging

### Section2: Flow Control and Reusable Logic

This section focuses on decision making and repetition in Bash.

- `condition_1 copy.sh`: file existence checks with `[[ -f ... ]]`.
- `condition_2.sh`: user validation and numeric comparison.
- `functions.sh`: defines reusable functions and checks for root privileges.
- `loops.sh`: demonstrates an infinite loop and a file-based `while` loop.
- `Until_loop.sh`: shows how `until` waits for a file to become non-empty.
- `for_loop.sh`: iterates over a numeric sequence.
- `case.sh`: identifies whether an IP looks like part of a private Class A or Class C range.
- `flow_control.txt`, ` output.txt`: support files used by the scripts.

Main topics in this section:

- File tests such as `-f` and `-s`
- String and numeric comparisons
- `if` / `else`
- Bash functions and return codes
- `while`, `until`, and `for` loops
- `case` pattern matching

### Section3: Network Automation Utilities

This section applies Bash to lightweight networking tasks.

- `ip_address_generator.sh`: generates host lists for a subnet using `for`, brace expansion, `sed`, and `printf`.
- `172.16.10-hosts_class_c.txt`: generated list of hosts in the `172.16.10.0/24` range.
- `subdomain_generator.sh`: prefixes subdomains from a wordlist onto a target domain.
- `port_watchdog.sh`: monitors a host and port using Bash TCP sockets via `/dev/tcp`, then logs a banner when the port opens.

Main topics in this section:

- Host list generation
- Wordlist-based subdomain building
- Port monitoring with pure Bash
- Simple service discovery and logging

Note: the directory on disk is named `Section3 ` with a trailing space.

### Section4: Concurrent Network Scanner

Section4 contains a more advanced scanner:

- `net_scan.sh`: a concurrent subnet scanner that:
  - validates CLI inputs
  - probes a target port across a subnet with `nc`
  - monitors ARP neighbor data with `ip`
  - tracks discovered hosts in an associative array
  - controls concurrency with background jobs
  - logs progress with timestamps and log levels
  - cleans up child processes on exit

Default behavior:

- Subnet: `192.168.152`
- Port: `22`
- Max host: `254`
- Max concurrent jobs: `120`

## Running the Scripts

Make a script executable:

```bash
chmod +x Section1/hello.sh
./Section1/hello.sh
```

Run a script directly with Bash:

```bash
bash Section1/arithmetic.sh
```

Examples:

```bash
bash Section1/positional_arguements.sh google.com
bash Section2/case.sh 192.168.1.10
bash 'Section3 /subdomain_generator.sh' example.com subdomains.txt
bash Section4/net_scan.sh --subnet 192.168.1 --port 22 --max-ip 50 --jobs 40
```

## Requirements

This repository is intended for a Linux environment with Bash available. Some networking scripts also expect common command-line tools such as:

- `ping`
- `nc`
- `ip`
- `sed`
- `printf`

Some scripts may require elevated privileges depending on the target operation or your local network environment.

## Learning Progression

The course content builds in this order:

1. Bash syntax, execution, variables, arrays, streams, and redirection.
2. Conditions, functions, loops, and case-based logic.
3. Practical host, subdomain, and port automation.
4. A more production-style concurrent network scanner with validation, logging, and cleanup.
